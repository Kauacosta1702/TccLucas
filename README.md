##  Sobre o Jogo
**Bico de Tucano: O Legado de Tito** é um jogo de aventura, exploração e culinária desenvolvido pela **Athenovie** como projeto de gamificação (advergame) para promover a cultura gastronômica e o veganismo.

Na história, acompanhamos **Lucas**, um jovem de 20 anos apaixonado por cozinha que decide viajar pelo mundo seguindo os passos de seu falecido avô, **Benedito (Tito)**. Guiado pelo antigo caderno azul do avô — o *Diário de Tito* —, Lucas explora diferentes países, aprende receitas tradicionais adaptadas para o universo 100% vegetal e descobre uma forma de salvar o restaurante da família em São Paulo.
